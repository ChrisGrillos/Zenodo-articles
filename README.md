# Zenodo-articles

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.XXXXXXX.svg)](https://zenodo.org/me/uploads)

Cutting edge Technology routes to experiment down.

This repository is archived on [Zenodo](https://zenodo.org/me/uploads) and a DOI is issued with every release.

## How It Works

This repository is connected to Zenodo via the [GitHub–Zenodo integration](https://help.zenodo.org/docs/github/). Each time a new GitHub release is created, Zenodo automatically archives a snapshot of the repository and mints a new DOI.

### Creating a Release (triggers a Zenodo archive)

1. Go to the **Releases** tab of this repository.
2. Click **Draft a new release**.
3. Enter a tag version (e.g. `v1.0.0`), a title, and release notes.
4. Click **Publish release**.
5. Zenodo will automatically archive the release and update the DOI.

> **Note:** After your first release, update the DOI badge at the top of this README with the actual DOI provided by Zenodo.
